# Save Image As (PNG, JPG, WebP)

A Chrome extension that adds **Save image as… → PNG / JPG / WebP** to the right-click menu on images.

Many websites serve images as WebP, which plenty of apps and upload forms don't accept.
This extension converts the image on your own device and saves it in the format you need.

## Privacy
- Images are converted locally. They are never uploaded anywhere.
- No analytics, tracking, ads, affiliate links or remote code.
- No "read and change all your data" permission at install. Access to a site is requested the
  first time you save an image from it, and you choose: that site only, or all sites.
- Revoke access any time: `chrome://extensions` → Save Image As → Details → Site access.

Full policy: [PRIVACY.md](PRIVACY.md)

## Features
- PNG, JPG or WebP from the right-click menu
- PNG keeps transparency; JPG gets a white background instead of black
- Keeps the image's original file name
- Works with large images and with images on sites you're logged into

## Known limitations
- SVG images can't be converted yet.
- Images generated by the page itself (`blob:` URLs) can't be read by extensions.

## Install from source
1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the repository folder.

## Permissions
| Permission | Why |
|---|---|
| `contextMenus` | Adds the right-click menu entries |
| `downloads` | Saves the converted file through Chrome's Save dialog |
| Site access (optional, asked at first use) | Reads the image you right-clicked so it can be converted |
